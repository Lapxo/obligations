# Estimates and decisions have distinct contracts

A finite decision is evaluated against a declared action space, state law, loss and tie rule. The same estimate can select different actions under different loss tables. An estimate or K_corr alone does not specify an action, accuracy or a universal scale of ceilings and floors.

Declared conditions:
- Finite named states and actions; normalized rational prior
- Every action-state loss is declared in a fixed loss unit
- Return every minimizing action; do not break an undeclared tie
- Estimation units and decision loss units remain distinct

a constraint evaluatorary: These are conditional finite decision tables, not a universal product law. The estimation-to-decision bridge remains open outside a declared operation.

Evidence status: definition and exact countermodels; no new runtime estimator or decision authority. T2 remains pending approval.
