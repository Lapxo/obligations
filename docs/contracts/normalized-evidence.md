# Normalized evidence

N is KL(P(X|positive)||P(X|negative)) divided by the same oriented KL of a named source marginal under those same conditional laws.

Inputs: two named truth conditions; complete rational normalized laws on named configurations; distinct source and configuration ids; named reference source in the population; binary64 log policy, declared resolution floor and support budget.

An injective duplication of coordinates preserves the two masses per joint state and the named reference marginal, hence the KL ratio. Conditional independent blocks make unnormalized group KL additive; ratios are additive only with a compatible common denominator.

A missing model or required evidence produces `unmeasured` with a cause. Invalid declared data refuses; it is never clipped, normalized or converted silently. The host separately bounds parsing, process lifetime and input bytes. The mathematical work budget does not bound arbitrary-precision bit complexity or wall time.

Does not establish: truth labels inferred from pairs; joint independence from lineage labels; universal N <= source count; probability of correct decision; admissibility as a valuation in the lattice paper; D_max approximates N outside a declared model; admission authority.

The output preserves the supplied population and model. a structured-data consumer represents it; a constraint evaluator judges authority, budgets and admissibility. The finite vectors are acceptance tests, not a rerun of the received scientific campaign.
