## 2. Theory (verbatim into docs/theory-2026-10.md)
### 2.1 Object and operation
A cell = name (form:hash) + origin + form + value held between a floor and a ceiling. One operation: FOLD = union in
the knowledge order; arrival order never decides. Meet empty between claims = FORK: kept with both names, closed
only by a signed DECLARE that leaves both values on record. A claim can be WITHDRAWN by id; the withdrawal is a cell;
history is append-only. Each place keeps its own clock; acting in A never moves B's epoch.
### 2.2 Laws
L1 Folding claims is union in the knowledge order; arrival order never decides.
L2 For intervals of a lattice, pairs suffice: every conflict has a witness of two (Helly number 2). Convex forms in
   R^d need witnesses up to d+1 (d=2 → 3). Cyclic forms (phase) without a declared cut have no finite Helly number;
   with a declared cut, h=2 on arcs not crossing it. Shannon partitions have no finite Helly number.
L3 Excluding any value from the maximal coincidence may exclude the truth; keeping the fork is the only correct action.
L4 Each entering origin closes bits and spends confidence; the guarantee of the meet is 1 − Σp UNDER DECLARED,
   JUSTIFIED failure probabilities p_i; if Σp ≥ 1 the bound is trivial and must be reported as such. Agreement
   and copy count do not estimate p.
L5 In the Shannon lattice, shared information may have no carrier: at most log₂n − 2 + 2/n bits.
L6 Information about the truth is bounded by the structure of causes, not by the number of witnesses; copies do not add.
L7 A closed group cannot measure its own reliability: for a cause covering all witnesses, P(unanimity on v) = c/n
   for every accuracy q, so q is unidentifiable from inside.
L8 Only dissent identifies what origins share; unanimity says nothing. For a partial cause, q is identified iff an
   outsider exists with error p ≠ (n−1)/n. Rank-breaking structures: same-set factors, singleton factors,
   cycle-covering factors, more factors than pairs.
L9 Which parameters can be measured is known before observing, from the pairs matrix of declared causes.
### 2.3 Verified facts (two independent origins: browser enumeration and a WebAssembly kernel, 13 Oct 2026)
F1 Extremal: over n equiprobable states, max RI(x,y) = log₂n − 2 + 2/n, attained only by the path on n+1 vertices
   (x groups edges by even endpoint, y by odd). Proof chain: lem-phi (φ(t) ≥ 2(t−1)) → lem-merge → lem-identity →
   lem-join → lem-meet → thm-extremal. Enumeration n=3..7: 0.251629, 0.500000, 0.721928, 0.918296, 1.093069;
   pair counts 25, 225, 2704, 41209, 769129 (Bell numbers squared → complete).
F2 Circle of 12 points, arcs of length 5 starting at 0, 4, 8: every pair meets, the three do not.
F3 Half-plane claims x+y≤12 (seller), x≥3 (buyer), y≥2 (carrier), x+y≥14 (auditor): CONFLICT, witness
   {seller, auditor}, 2 of 4. Minimal example needing three: x ≥ 0, y ≥ 0, x + y ≤ −1 (pairwise consistent,
   jointly empty). Both go in as vectors.
F4 Phase: RI = log₂(n/p) − h(s/p) with n states, period p dividing n, shift s with 0 ≤ s < p, h the binary entropy;
   worst case is near-phase, not anti-phase. (Author to confirm the domain; until then the vector carries these
   hypotheses explicitly.)
F5 M/4: with a common cause c of accuracy q, C = log₂n − c·[h(q) + (1−q)·log₂(n−1)]; dissent
   d = (1−c)·[1 − (1−p)² − p²/(n−1)]. Sample n=4, c=1/5: one covering factor q=0 → 1.683 bits; {A,B},{A,B} → 1.430;
   {A,B},{C,D} → 1.937; triangle {A,B},{B,C},{A,C} → 1.835; q=1/2 → 1.642. Numeric policy: binary64-log2.
   Negative sample (each a named refusal): missing q → refuse; 2 witnesses requesting c → unmeasured; 3 binary
   witnesses → unmeasured; perfect agreement → no-dissent; copies → same bound; partial governance → unmeasured.
   HOW FACTORS GOVERN in duplicated/disjoint/triangle models is NOT fully specified: region stays open (§5).
### 2.4 Universal primitives (13–14 Oct 2026)
P1 Obligations: a cell may declare names it needs; an obligation is an open region of form bytes inside the cell
   (not an edge). Bytes hashing to the name narrow it to a point; received bytes are themselves a cell whose open
   regions fold inside the parent's. Terminates: the knowledge order is well-founded, plus an instruction budget.
P2 Byte regions: open / resolved / fork (two holders, two byte sets: both kept) / unmet (no holder: stop, name it).
   Wrong bytes are refused, never patched.
P3 Named core: a result declares the names it depends on; validity is a function of that core only.
P4 Root as a cell of names: a list of names folds into one name. Atoms (form bytes) have no dissent; dissent lives
   in claims. The atom zero (fold/hash/assemble) is trusted out of band; in Bound it is the WebAssembly kernel.
P5 Name in the fragment: a link carries #form:hash, not a place; the form is in the name because it declares how
   claims combine (Helly order). Expected addresses: hash("answer to claim X") is known before the answer exists.
P6 Paper as holder: a QR holds a name or small bytes (one QR 2,953 B; A4 sheet ≈140 KB); two tiers of "belongs to
   no one": complete-on-paper, and named (bytes exist while someone keeps them).
P7 Copresence: commit-reveal; horizon ≥ max latency; decisions with duration; actions as intervals.
P8 Fold-as-you-go: resolve by frontier, by need, by proximity.
P9 Universality test: a primitive enters only if it means the same in a game, a news story and a sensor without
   code change. Never in a contract: ticks, demos, games, pages, APIs.
P10 Derived regions: form=derived, value = f(named regions), closing policy eager|deferred (from Scion's derived
   data; passes P9). Verification is a claim, not a gate: implementation claims fold immediately; verification is
   a derived region closed later. Cost of folding a cell ∝ the cell, never the world.
