# The obligatory cell and its declaration

An obligatory cell is read over a supplied lattice, epoch and dependency world. Required and signed bounds, live attributed claims and rest remain distinct parts of one object. A declaration is a demand/limit projection; it is not a replacement cell.

No new Cell, authority evaluator or fixed set of application regions. A witnessed local widening never travels. Cell state counts named origins, not authenticated or independent causes.

The deterministic reader consumes the declared finite fixture and its sealed expected answer. It does not authenticate or admit a claim. The contract, positive and negative in each of two unrelated contexts, and captured process output are bound by digest. No scientific experiment is run.

## Justification

`parts` computes required/signed marks and the meet of live claims in the supplied lattice. Its returned origins are the original live claims. `declaration` reads the ranked endpoints. `refine` changes only the coordinate resolution. A widening passed to `mark` with travelling reach rejects before any propagation. This records the existing API convention; no universal scalar scale is asserted.
